## Phạm vi và kết quả

Đã dò cấu trúc toàn repo, quy tắc CLAUDE/SPEC, data pipeline, schema processed, scripts/tests/config và điểm nối API/UI. Các gói querygen/train/eval chưa có pipeline tương ứng; retrieval trước phase này chỉ có hàm prefix E5. API vẫn là khung trả MODEL_NOT_READY, không được tích hợp trong phase BM25. Quét cú pháp Python trên toàn source repo đạt; đây không phải audit bảo mật toàn repo.

Pipeline: NFC/whitespace → VNCoreNLP wseg → lowercase token → chỉ bỏ token toàn dấu câu Unicode P; giữ symbol, dấu, số, phủ định và từ ghép. Chỉ unigram. `bm25s` Lucene, tham số đọc từ YAML; top-200 chunk, thứ tự hòa điểm cố định, MaxP rồi top-10 Điều. Query lặp token đóng góp lặp theo thư viện. Corpus/query gốc được giữ nguyên.

## Tái lập

Từ root repo, cài theo README và đặt `JAVA_HOME` tới runtime Java 64-bit. Môi trường đã chạy: Python 3.11.9, Java 1.8.0_471, bm25s 0.2.14, py-vncorenlp 0.1.4, pyjnius 1.9.0; NumPy/SciPy được ghi trong summary/manifest và ghim ở requirements-bm25.txt.

File query gốc local có hash bên dưới; đặt `$queryCsv` tới bản CSV tương ứng. CLI chỉ kiểm tra cấu trúc đọc/ID/rỗng, không tự sửa hoặc lọc chất lượng 500 query đã được người dùng kiểm tra.

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/run_bm25.py --config configs/bm25.yaml --queries $queryCsv --build
.\.venv\Scripts\python.exe -X utf8 scripts/run_bm25.py --config configs/bm25.yaml --queries $queryCsv --output .scratch/bm25-replay-v2
.\.venv\Scripts\python.exe -m pytest -q -rs
.\.venv\Scripts\python.exe -m ruff check src/retrieval/bm25.py src/retrieval/text.py scripts/run_bm25.py scripts/download_vncorenlp.py tests/test_bm25.py
.\.venv\Scripts\python.exe -m ruff format --check src/retrieval/bm25.py src/retrieval/text.py scripts/run_bm25.py scripts/download_vncorenlp.py tests/test_bm25.py
```

Các lệnh build/replay/test/lint trên đã chạy exit 0. Muốn chạy lại phải chọn thư mục output/index chưa tồn tại (hoặc sửa paths trong config cho build mới); chương trình không ghi đè. CSV/model/index/output đều local, không commit. Script tải VNCoreNLP có unit test với HTTP mock; việc tải thực tế trong phiên dùng cùng revision và đúng ba file bằng HTTPS, chưa kiểm chứng riêng CLI tải trên máy sạch.
