Phase này cung cấp E5 gốc chạy local, không dùng API ngoài cho retrieval; chưa thay thế fine-tune, gán nhãn, split, đánh giá hoặc demo. Bản rubric có đoạn OCR hỏng; không suy diễn đoạn không đọc rõ hoặc tuyên bố đạt điểm.

Dùng cùng corpus và CSV với BM25. Query được NFC/gộp khoảng trắng đúng một lần; passage giữ nguyên chunk_text. Prefix dùng chung e5_format.py. Không VNCoreNLP hoặc word n-gram. AutoModel/AutoTokenizer local-only: mean pooling theo attention mask, L2, fp32, không autocast/TF32. Không truncate âm thầm. Exact dot product toàn bộ chunk; chung tie-break/top-200/MaxP/top-10 với BM25.

## Tái lập

Từ root repo, cài requirements.txt và requirements-e5.txt. Script download_e5.py đã chạy thành công, tải sáu file theo revision và ghi checksum vào download.json. Run chỉ nạp local_files_only=True, trust_remote_code=False, safetensors; không tự gọi mạng. Đặt `$queryCsv` tới CSV có query_id/query.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pip install -r requirements.txt -r requirements-e5.txt
.\.venv\Scripts\python.exe -X utf8 scripts/download_e5.py --config configs/e5.yaml
.\.venv\Scripts\python.exe -X utf8 scripts/run_e5.py --config configs/e5.yaml --queries $queryCsv --build
$env:HF_HUB_OFFLINE='1'
$env:TRANSFORMERS_OFFLINE='1'
.\.venv\Scripts\python.exe -X utf8 scripts/run_e5.py --config configs/e5.yaml --queries $queryCsv --output .scratch/e5-replay
.\.venv\Scripts\python.exe -m pytest -q -rs
```

Download/build/replay đã chạy exit 0. Thư mục model/index/output phải chưa tồn tại khi tạo mới. Để chạy lại, chọn paths/output mới; không xóa artifact chỉ để làm lệnh pass. Config CUDA yêu cầu GPU; máy CPU cần cấu hình device và torch phù hợp trước build, không fallback âm thầm. Đổi runtime/encoding/model yêu cầu index mới vì manifest so khớp nghiêm ngặt. Chưa thử máy sạch hoặc đồng nhất bit giữa hardware khác nhau.

Index: indexes/e5_s2/. Output: data/interim/e5_s2/run.trec, candidates.jsonl, warnings.jsonl, summary.json. Model/index/output local được Git bỏ qua. Candidate chưa gán nhãn, có nội dung Điều đầy đủ và shuffle theo seed, không có rank/score/source-query metadata. Chưa hợp nhất với BM25; cần dedup union và shuffle lại trước gán nhãn.
