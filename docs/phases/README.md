# Hồ sơ bàn giao từng phase

Khi một phase có kết quả thật, sao chép [mẫu bàn giao](../templates/phase_handoff.md) thành `NN_ten_phase.md` ở đây. Một hồ sơ ghi nhận đầu ra code, review và phần trình bày của đúng mốc được giao.

Hiện chưa lập hồ sơ bàn giao trình bày hoàn chỉnh. EDA là phase đầu tiên có thể tiếp nhận để tạo notebook/hình; xem [tiến độ và nguồn bằng chứng](../README.md). Không tạo trước kết quả cho các phase chưa chạy.
